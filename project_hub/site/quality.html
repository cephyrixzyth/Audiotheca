Safety defaults
Audiotheca is designed as a local operator tool. The API defaults to 127.0.0.1; scans and file-moving operations use explicit dry-run/confirmation controls; path allowlists guard library operations.

Security boundaries

The hub is separate from the Audiotheca API. It has no write endpoint and does not load configuration, secrets, scan reports, or library data. It binds to 127.0.0.1 and serves a fixed allowlist of static pages and project documents.
