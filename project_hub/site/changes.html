Privacy and security

  • AI metadata lookup skips symlinked files and directories.
  • ZIP CRC diagnosis now caps archive size, entry count, and streamed decompressed bytes.
  • Release scripts refuse to force-move an existing release tag.

Dependencies and builds

  • Vitest and its lockfile were updated; the last recorded npm audit had no known vulnerabilities.
  • Pydantic is allowed to resolve its matching pydantic-core dependency.
  • The Tauri lockfile version was aligned with the manifest.

Docker, scan, and desktop

  • VPN-profile requests route through the Gluetun network namespace to SearXNG.
  • Engine launch path and identify-only preset behavior were corrected.
  • Desktop API selection now trusts the sidecar URL instead of probing neighboring ports.
